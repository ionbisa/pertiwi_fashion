# Pertiwi Fashion

Website katalog dan marketplace fashion untuk koleksi pajamas, mukena, daster, serta aksesori.

Proyek ini dikembangkan untuk menghadirkan pengalaman belanja yang mudah, nyaman, dan menarik dengan tampilan yang feminin, elegan, serta profesional.

## Kategori Produk

- **Pajamas** — Koleksi setelan baju tidur.
- **Mukena** — Koleksi perlengkapan ibadah wanita.
- **Daster** — Koleksi pakaian santai sehari-hari.
- **Aksesori** — Pelengkap gaya dan kebutuhan fashion.

## Konsep Desain

Tampilan website mengutamakan foto produk, navigasi yang jelas, dan tata letak yang rapi.

Arah visual:

- Blush pink untuk kesan lembut dan feminin.
- Ivory atau cream sebagai warna dasar.
- Aksen emas untuk sentuhan elegan.
- Warna gelap untuk menjaga keterbacaan teks.
- Tampilan responsif untuk desktop, tablet, dan ponsel.
